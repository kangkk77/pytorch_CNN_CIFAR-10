# CIFAR-10 图像分类

- `train.py`：原始 CNN，包含两层卷积和三层全连接。
- `ResNet-18.py`：适配 CIFAR-10 的 ResNet-18，从头训练，不加载预训练权重。

## 原始 CNN 结构

| 层 | 操作 | 输出尺寸 |
| --- | --- | --- |
| conv1 | Conv2d(3→6, 5×5) + ReLU + MaxPool(2, 2) | 6×14×14 |
| conv2 | Conv2d(6→16, 5×5) + ReLU + MaxPool(2, 2) | 16×5×5 |
| flatten | 展平 | 400 |
| fc1 | Linear(400→120) + ReLU | 120 |
| fc2 | Linear(120→84) + ReLU | 84 |
| fc3 | Linear(84→10) | 10（各类 logits） |

- 卷积层默认 stride=1、无 padding，特征图经 5×5 卷积后每边减 4，再经 2×2 最大池化边长减半。
- 最后一层不接 softmax，直接输出 logits，由 `nn.CrossEntropyLoss` 内部完成 log-softmax。
- 全网络约 62,006 个可训练参数（含偏置）。
## 训练配置
- 损失函数：`nn.CrossEntropyLoss`（交叉熵）
- 优化器：SGD，`lr=0.01`，`momentum=0.9`
- batch size：128，共训练 20 个 epoch
- 预处理：`ToTensor` 后用 `Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5))` 归一化到 [-1, 1]
- 设备：自动选择 CUDA（`cuda:0`）或 CPU
- 评估：训练结束后输出测试集整体准确率，以及 10 个类别各自的准确率

## 对照实验：训练轮数与数据增强

以下为手动记录的实验结果，分别比较 20 轮和 40 轮训练下的 Baseline（无数据增强）与 Augmentation（数据增强）。这些结果来自已有实验，本次未重新训练；恢复后的 `train.py` 保持 GitHub 原版，实验记录不表示该脚本会自动运行全部四组实验。

| 训练轮数（epoch） | 实验设置 | 训练集准确率（Train Accuracy） | 测试集准确率（Test Accuracy） | 训练与测试准确率差距（百分点） |
| --- | --- | --- | --- | --- |
| 20 | Baseline（无数据增强） | 79.02% | 64.37% | 14.65 |
| 20 | Augmentation（数据增强） | 67.20% | 66.13% | 1.07 |
| 40 | Baseline（无数据增强） | 88.40% | 61.23% | 27.17 |
| 40 | Augmentation（数据增强） | 72.72% | 70.75% | 1.97 |

### 结果分析

- **相同轮数下，数据增强提高了测试集准确率**：20 轮时提高 1.76 个百分点（64.37% → 66.13%）；40 轮时提高 9.52 个百分点（61.23% → 70.75%）。
- **Baseline 延长训练后出现更明显的过拟合迹象**：从 20 轮到 40 轮，训练集准确率提高 9.38 个百分点，但测试集准确率下降 3.14 个百分点，训练与测试准确率差距从 14.65 扩大到 27.17 个百分点。
- **数据增强实验在 40 轮时表现更好**：相较 20 轮，训练集准确率提高 5.52 个百分点，测试集准确率提高 4.62 个百分点；训练与测试准确率差距仍较小。
- 本次四组记录中，**40 轮 + 数据增强**的测试集准确率最高，为 **70.75%**。这些记录支持数据增强有助于改善泛化表现，但尚未提供多次重复实验的均值和标准差。

### 模型与训练配置

- 使用 `torchvision.models.resnet18(weights=None, num_classes=10)`，不加载 ImageNet 预训练权重。
- 输入为 CIFAR-10 的 `3×32×32` 图片；首层卷积改为 `3×3`、`stride=1`、`padding=1`，输出 64 个通道。
- 开头的最大池化替换为 `nn.Identity()`，保留后续残差层的下采样，最后输出 10 类 logits。
- batch size 为 128，训练 20 个 epoch；损失函数为交叉熵，优化器为 SGD（`lr=0.01`、`momentum=0.9`）。
- 使用与原始 CNN 相同的归一化，无数据增强、无学习率调度。
- 自动选择 CUDA 或 CPU；训练结束后输出整体和各类别测试准确率。
